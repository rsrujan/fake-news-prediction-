# 📰 Fake News Prediction Using Machine Learning

This project is a **Fake News Detection System** that utilizes classical Machine Learning algorithms to identify whether a given news article is **real** or **fake**, based on its content. The goal is to help curb misinformation by providing a simple and efficient model to classify news text.

## 🔍 Features

- ✅ Classifies news as **Fake** or **Real** based on content.
- 💡 Uses **TF-IDF Vectorization** for feature extraction.
- 🧠 Implements multiple Machine Learning models:
  - Logistic Regression
  - Passive Aggressive Classifier
  - Naive Bayes (optional)
- 📊 Evaluates models with accuracy and confusion matrix.

## 🚀 Technologies Used

- Python (Jupyter Notebook)
- Pandas & NumPy for data handling
- Scikit-learn for model training and evaluation
- TF-IDF for text feature extraction
- Matplotlib & Seaborn for visualizations

## 📁 Files in This Repository

- `Fake_news_prediction.ipynb`: Main notebook containing data preprocessing, model training, and evaluation.
- `README.md`: Project documentation and overview.
- `requirements.txt`: (Optional) Python dependencies.

## 🧪 How It Works

1. Load a labeled dataset of real and fake news articles.
2. Clean and preprocess the text data.
3. Convert text to numerical vectors using **TF-IDF**.
4. Train ML models and evaluate their performance.
5. Predict the label of new/unseen news articles.
